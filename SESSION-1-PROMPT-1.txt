This project is Guardian: a free, open-source health guardian app (Android + iOS) for elderly people living at home, and our Kiroween 2026 Frankenstein entry. Binding rules from steering: Guardian NEVER dials 911 or any emergency number — dispatch is a monitored-partner interface (Noonlight class), sandbox only in the demo build. Simulated data is always labelled simulated. The wearer owns every share; the cancel window is always honoured. The escalation engine in engine/ is COMPLETE and tested (engine.js state machine, hash-chained event log, scheduler, notifier interface with mock implementations, dispatcher with a Noonlight-sandbox payload builder, dispatch disabled): it is disclosed pre-existing code — integrate and verify it, do not rewrite it.
